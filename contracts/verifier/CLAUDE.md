# contracts/verifier

On-chain Groth16 BN254 verifier contract. Auto-generated by `soroban-verifier-gen` then patched.

## Key Files

| File | Purpose |
|------|---------|
| `src/lib.rs` | `verify_proof(proof, pub_signals) -> bool` and `vk_hash() -> BytesN<32>` |
| `src/vk.rs` | Hardcoded verification key bytes (alpha, beta, gamma, delta, ic) — auto-generated |
| `src/test.rs` | Tests with snarkjs proof fixtures (valid + tampered) |

## Verification

Pairing check: `e(pi_a, pi_b) * e(alpha, beta) * e(vk_x, gamma) * e(pi_c, delta) == 1`

VK hash = SHA-256 of concatenated VK bytes (circuit identity fingerprint).
