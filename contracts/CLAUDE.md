# contracts

Soroban smart contracts for Amoeba's ZK compliance pipeline. Workspace members in root `Cargo.toml`.

## Contracts

| Contract | Purpose |
|----------|---------|
| **verifier** | On-chain Groth16 BN254 pairing check. Auto-generated by `soroban-verifier-gen`, synced via `sync-verifier-from-ceremony.sh`. Exposes `verify_proof()` and `vk_hash()`. |
| **compliance** | Orchestrates compliant transfers. Manages issuers, corridors, nullifiers, epoch validation. Delegates proof verification to verifier contract, then calls SAC `transfer()`. |
| **mock-sac** | Minimal mock Stellar Asset Contract implementing `TokenInterface` for testing. |

## Conventions

- `#![no_std]` with `soroban-sdk`
- Snapshot tests in `test_snapshots/` per contract
- Events emitted for all state changes
- Admin-guarded functions with `require_auth`
- 19 error variants in compliance covering all failure modes
